# Hoerhilfeplus - Advanced Hearing Solutions

[**Live Website**](https://hoerhilfeplus.com)

Hoerhilfeplus is a specialized healthcare landing page focused on the "AURIS PRO" line of invisible in-ear hearing aids. Designed for the German medical technology market, the platform delivers technical clarity, professional credibility, and high-performance user engagement.

---

## 💼 Client Project
This platform was custom-developed specifically for a **German-based client** in the healthcare and medical device sector. The project involved creating a trust-centric digital presence that complies with German advertising standards (Anzeige) and medical data protection regulations.

## 🛠️ Tech Stack
- **HTML5**: Semantic medical-grade markup for SEO and accessibility.
- **Vanilla CSS**: Clean, professional design system using the **Inter** font family. Features a high-contrast navy and red palette, mobile-responsive layouts, and specialized UI components like floating legal triggers.
- **JavaScript**: Custom implementation for asynchronous loaders, persistent cookie consent, and interactive FAQ systems.

## 🌟 Key Features
- **Medical Trust Building**: Integrated testimonial sliders, detailed feature grids, and risk-free trial documentation to maximize consumer confidence.
- **High-Conversion UX**: Fast-loading assets and prominent CTA placements targeting a 50% seasonal discount.
- **Comprehensive Legal Infrastructure**: Built-in modals for Impressum, Privacy (DSGVO), and Return Policies, including floating persistent triggers for easy access as per regional requirements.
- **App-Like Feel**: Features a custom pre-loader and mobile-first navigation for a modern, seamless experience.
